# Fuzzy-control-for-autonomous-particle-synthesis
Device control system for particle synthesis with fuzzy control.

List of devices used, all devices are controlled with RS-232 serial communication.
- balances: HS3200S, HS3002 (HANSUNG)
- valve: MVP valve 3-5 (Hamiltion)
- peristaltic pump: LabV1-III (SHENCHEN)
